# Computer Graphics Game

A simple 2D game developed using C++ and OpenGL (GLUT) as a university
project for the Computer Graphics course.

## Features
- Graphics rendered with OpenGL
- Background images and textures
- Sound effects for winning and losing


## Technologies
- C++
- OpenGL
- GLUT

## How to Run
1. Install a C++ compiler and the GLUT/freeglut library.
2. Download or clone this repository.
3. Open `lab6p.cpp` in your IDE (Visual Studio / Code::Blocks) and link OpenGL and GLUT.
4. Build and run. Keep the images and sound files in the same folder as the executable.
